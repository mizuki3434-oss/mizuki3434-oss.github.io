NoctraxLAB Live

NoctraxLAB Live is a private tool used only by the owner of the YouTube channel NoctraxLAB to schedule and manage the channel's own 24/7 lo-fi live streams through the YouTube Data API.

Privacy Policy

This tool is used solely by the channel owner on their own YouTube account. It is not offered to the public.

  • Data accessed: the owner's own YouTube channel live broadcast and live stream settings, via YouTube API Services.
  • Use: only to create, start, update and end the channel's own live broadcasts.
  • Storage: the OAuth token is stored only on the owner's private server and is never shared, sold or transferred to third parties.
  • No other users: no personal data of any other person is collected.
  • Revoking access: access can be removed at any time at Google Account permissions.

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact: via the NoctraxLAB YouTube channel.
